Equipo 8, Servidores II, Universidad de Sonora	

## Guía para levantar la aplicación
1. Instalar Docker Engine y Docker Compose en tu equipo
2. Agrega tu usuario actual al grupo Docker
3. Clonar el repositorio https://github.com/equipounderdog8/inventario.git
4. Entrar a la carpeta del repositorio
5. Copiar el contenido del archivo .env.ejemplo a un archivo .env
6. Cambiar las contraseñas de MySQL en el archivo .env
7. Levantar la aplicación con Docker Compose
